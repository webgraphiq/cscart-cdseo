# CDSEO for CS-Cart

**🛑 PREMIUM ADD-ON: This repository does not contain the open-source code. It serves as the official listing and documentation page for the WebGraphiq premium add-on.**

**CDSEO** is an SEO add-on for CS-Cart and Multi-Vendor. It sets a canonical path for each item, redirects disabled items, and adds the extra fields Google uses for rich results and structured data.

## [🛒 Buy & View Live Demo](https://www.webgraphiq.com/cs-cart-seo-optimization-canonical-url-cdseo-v4.html)

One-time license. The current price and the live demo are on the product page.

## Why store owners use it

- Each product, category, or page can use its own canonical path instead of the default CS-Cart URL.
- A disabled item can 301 to a URL you choose, so old links do not end on a dead page.
- Store-wide 404 traffic can go to one page, or return a 301 instead of a 404.
- Company profile links for Facebook, X, and YouTube are available for the structured-data output.
- A `priceValidUntil` value can be set for the price snippet.

## What you control

- Canonical path, without the domain, for example `apparel/men/seo-link`.
- Full URL used as a 301 when that item is disabled.
- One 404 destination for the shop, with the option to send a 301 instead of a 404.
- Company Facebook, X, and YouTube URLs.

## Requirements

- CS-Cart or Multi-Vendor **4.12.1** or newer, including **4.21**
- PHP **8.3** or a current 8.x release used by that shop
